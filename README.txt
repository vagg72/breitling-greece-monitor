BREITLING GREECE MONITOR — iPHONE PWA v1.0

Τι είναι: Στατική εφαρμογή Safari/PWA χωρίς ιδιωτικό server. Αποθηκεύει νέα και αγαπημένα τοπικά.

ΔΗΜΟΣΙΕΥΣΗ
1. Ανεβάστε ΟΛΑ τα αρχεία αυτού του φακέλου σε HTTPS static hosting (π.χ. GitHub Pages ή Netlify). Δεν αρκεί να ανοίξετε το index.html από Files στο iPhone.
2. Ανοίξτε την HTTPS διεύθυνση στο Safari του iPhone.
3. Επιλέξτε Κοινή χρήση > Προσθήκη στην οθόνη Αφετηρίας.

ΠΕΡΙΟΡΙΣΜΟΙ
- Η ανάκτηση Google News RSS βασίζεται σε δημόσιο τρίτο proxy (api.allorigins.win). Μπορεί να αποτύχει λόγω CORS, rate limits ή διαθεσιμότητας. Δεν υπάρχει εγγυημένη αυτόματη συλλογή.
- Τα social media είναι σύνδεσμοι προς δημόσιες αναζητήσεις, όχι αυτόματη παρακολούθηση.
- Δεν υπάρχουν push notifications, background polling ή 24/7 παρακολούθηση.
- Τοπικά δεδομένα στο Safari μπορεί να χαθούν με εκκαθάριση δεδομένων ιστοτόπου. Χρησιμοποιήστε Εξαγωγή JSON για backup.
- Δεν συνδέεται ούτε υποστηρίζεται επίσημα από την Breitling.
